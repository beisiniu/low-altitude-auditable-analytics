## 三步开始

在**本文件夹根目录**打开终端：

```bash
pip install -r requirements.txt
python tools/check_env.py
python tools/build_all.py
```

第三条会重建数据、跑 12 项单测、跑 24 题主评测、生成对比表。看到下面这行就说明一切正常：

```text
ALL numeric 24/24 -> 24/24 | relevance 0.399 -> 0.990 | verifiable numbers 24 -> 242
```

**这一步不需要大模型、不需要网络、不需要任何 key。**

---

## 关于大模型

确定性主实验完全不需要模型。补充的本地 LLM 实验需要权重（合计约 7.5 GB），**故意没有打包**：

```bash
python tools/download_models.py --model 1.5b   # 最小，约 1.1 GB
python tools/download_models.py --all          # 全部四档 + 推理引擎
```

下载地址、校验大小、三个可选放置位置、环境变量、内存要求和 `--no-repack` 这个必填参数，全部写在 `models/README.md`。脚本会**自动找模型**，新电脑没有 E 盘也不用改代码。

## 一句话结论

> 给一个「AI 不许自己算数、每个数字都要被程序重新验一遍」的开源分析工具，装上低空无人机配送的专属能力；用 24 道题和四轮实验诚实量出：数值正确率没提升（基线本来就能算对），但答案完整性 0.399→0.990、可复核数字 24→242；换 1.5B/3B/7B 三档本地模型后，模型自写 SQL 从 0→5/24，选工具稳定 22–23/24，差距仍没消失。
